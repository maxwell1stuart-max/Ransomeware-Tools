Remote RAM Acquisition

How Remote Acquisition Works

  1. The Pi scans the local network for Windows machines with SMB (port 445) or WinRM (port 5985) open.
  2. You provide credentials for a local Administrator account on the target machine.
  3. RFT uploads winpmem (open-source memory tool) to the target via SMB ADMIN$ share.
  4. winpmem runs on the target and creates a RAM image in C:\Windows\Temp\.
  5. RFT downloads the RAM dump back to the Pi for offline analysis.
  6. winpmem is deleted from the target — minimal footprint.

Note: This requires Administrator credentials on the target and that the target is reachable from the Pi over the network. Use only on machines you are authorized to examine.
